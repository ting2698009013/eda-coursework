# AI 辅助说明

这是个人课程学习项目，开发过程使用了 AI 辅助。辅助涉及资料检索、研究范围与对照实验设计、Python 代码和测试、工具下载脚本、数据分析以及说明文档；不应把这些内容表述为完全独立手写的研究成果。

公开版本保留可执行测试与实验配置，避免只展示生成的文字结论。实验包含不支持新方法优越性的结果：整序列局部搜索在开发集上的改善没有延续到新电路。

2026-10-11 的公开整理补充了跨平台运行说明、CI、第三方许可说明、公开数据一致性检查，并缩小了发布包范围。后续学习时仍需独立理解 ABC 的操作、搜索预算、等价验证和统计口径；对外介绍时应区分个人学习、AI 辅助实现和上游工具的贡献。
