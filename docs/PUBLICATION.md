# 公开副本的范围

本仓库从个人 EDA 课程项目中整理，快照日期为 2026-10-11。

## 包含

- 最终版 Python 搜索与实验框架、测试、组合 Verilog 示例，以及可独立使用的下载、审计、重放和分析脚本。
- EPFL 固定提交 `82d8cc6910419298e713a46644ed59fd3df53038` 的 20 个电路、来源清单、SHA-256 与原 MIT 许可证。
- 初始实验、小试跑及 E1–E4 的参数配置。
- 已完成的 E1–E5 扩展实验报告、图表、主比较的统计摘要与 2,576 行逐次指标。CSV 保留原值，没有挑选有利运行。

## 未包含

课程任务 PDF、演示文稿、工具安装包/二进制、Python 缓存、开发中间分支，以及原始网表、候选轨迹、CEC 日志和历史源码压缩快照。

报告中的“审计通过、重放通过”是原实验完成时的记录。公开 CSV 中的验证状态来自原摘要，不能替代再次运行真实等价检查。`scripts/check_publication.py` 只检查公开文件完整性、计数与主比较统计一致性，不声称复查了未发布的原始网表。

## 怎样复现

公开最终源码可以在附带基准上重新运行搜索、验证和批量实验。命令见首页。对于新实验，程序会生成自己的输入、输出、原始日志与源码快照，供独立审计和重放。

历史阶段 E1/E2、E3、E4/E5 的实现版本不同，公开仓库保留的是最终版。因此，“用当前源码和旧参数重新实验”与“逐字节恢复历史阶段”是不同任务；本仓库未提供后者所需的旧源码快照。限时搜索也会受到机器负载影响。

扩展主指标为先在每个电路内平均 log(LUT 比值)，再对电路等权平均；区间对相邻时段块配对重采样 10,000 次。原始 300 次实验采用中位数后取几何平均的口径，未混入这些 CSV。
